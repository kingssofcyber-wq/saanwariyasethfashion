SAANWARIYA SETH FASHION — START HERE

1) Extract this ZIP.
2) Open CMD in the saanwariya-storefront-premium folder.
3) Copy .env.example to .env and set DATABASE_URL, AUTH_SECRET, ADMIN_EMAIL and ADMIN_PASSWORD.
4) Run:
   npm install
   npx prisma db push
   npm run db:seed
   npm run dev
5) Open http://localhost:3000
6) Admin portal: http://localhost:3000/admin
   Log in first with the ADMIN_EMAIL and ADMIN_PASSWORD configured in .env.

IMPORTANT:
- Node.js 22 is the configured runtime.
- Do not use the sample admin password on a public website.
- The store is COD-oriented; payment gateway and courier integrations still need configuration.
- Flipkart API/feed requires valid official affiliate access; this project does not scrape Flipkart.
- Demo photography and inventory must be verified/replaced with true product data before sales.
- Read HANDOUT.md for full setup, route map, deployment notes and limitations.
