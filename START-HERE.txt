SAANWARIYA SETH FASHION — START HERE

1) Extract this ZIP.
2) Open CMD in the saanwariya-storefront-premium folder.
3) Copy .env.example to .env.
4) Set DATABASE_URL, AUTH_SECRET, ADMIN_EMAIL, ADMIN_NAME and a private ADMIN_PASSWORD (minimum 16 characters).
5) Run:
   npm install
   npm run db:setup
   npm run db:verify
   npm run dev
6) Open http://localhost:3000
7) Admin sign-in: http://localhost:3000/login?next=/admin
   Admin portal: http://localhost:3000/admin

DEFAULT ADMIN EMAIL / LOGIN USERNAME:
   admin@saanwariyasethfashion.com

ADMIN PASSWORD:
   Set your own private password as ADMIN_PASSWORD in .env / Hostinger Environment Variables before running db:setup. It is intentionally not stored in this ZIP or committed to GitHub.

DATABASE TABLES CREATED BY PRISMA:
   User, Product, Order, OrderItem, ContactMessage, ProductReview
   Wishlist and Compare are browser-side features in this version.

IMPORTANT:
- Node.js 22 is the configured runtime.
- Never commit .env or share database/admin credentials.
- Run npm run db:setup from the app project directory connected to the Hostinger database. It creates/updates tables and seeds the admin plus 30 demo products.
- Re-running the seed refreshes matching demo catalogue rows; back up edited demo product data first.
- The store is COD-oriented; payment gateway and courier integrations still need configuration.
- Flipkart API/feed requires valid official affiliate access; this project does not scrape Flipkart.
- Demo photography and inventory must be verified/replaced with true product data before sales.
- Read DATABASE-ADMIN-SETUP.md and HANDOUT.md for details.
